The stack:
    dedicated chunk of memory, a register keeps track of where we are in the stack currently, (SP -> stack pointer)
    starts on high address in memory, grows down(heaps grow from bottom up)
    push ax, pop ax, push -> sub sp + mov [sp], ax, pop -> mov ax, [sp], add sp
    call -> push ip + jmp
    ret -> pop ip + jmp
    arguments to function on stack or in registers (depends on calling convention)
    Stack can get reserved for arrays etc., you store the pointer to the start of the array to for example bx and use it as usual
